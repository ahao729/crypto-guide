> 最后核对：2026-10-29。各国/地区税制不同，本文只做通用框架和记录清单，不构成税务建议；请以当地税法和专业顾问意见为准。

## 先说结论

- 加密资产税务的核心不是“有没有赚钱”，而是**有没有发生应税事件**；
- 买入、持有、钱包间转账通常不产生应税事件，卖出、币币兑换、消费、赚取收益通常需要记录；
- 最容易出问题的是：没有成本记录、把币币兑换当“没卖”、忽略空投/质押/DeFi 收益；
- 只靠交易所导出不够，CEX、钱包、链上、DeFi 要合并记录。

## 一、哪些行为通常需要申报

| 行为 | 常见处理 | 要保留什么 |
|---|---|---|
| 法币买入加密资产 | 通常只是取得成本，不立即应税 | 成交价、数量、手续费、时间 |
| 卖出换法币 | 通常产生资本利得/损失 | 买入成本、卖出价、手续费 |
| 币币兑换（BTC→ETH） | 多数地区视为“处置” | 原币成本、兑换时价值 |
| 用币消费/支付 | 通常视为处置 | 消费时价值、原成本 |
| 质押/借贷/流动性收益 | 通常作为收入或增加成本基础 | 数量、时间、价值、协议 |
| 空投/分叉 | 视地区规则，可能按收入或成本处理 | 取得时间、价值、项目 |
| NFT 买卖 | 可能涉及资本利得/收入 | 铸造/买入/卖出记录 |
| 钱包间转账 | 通常不应税，但必须保留归属 | 地址、网络、数量、时间 |

> “通常”不代表你所在地区一定如此；如果当地把加密资产视为财产、证券或商品，处理会不同。

## 二、成本基础怎么记

成本基础 = 你取得资产时支付的价格 + 合理手续费。

常见方法：

- **FIFO**：先进先出，默认但可能不最优；
- **Specific ID**：指定卖出哪一批资产，需要完整记录；
- **平均成本**：部分地区允许，部分地区不允许。

不要年底才补记录；每笔交易当天记录最可靠。至少保留：

- 时间、平台/钱包、币种、数量；
- 法币价值（或兑换时对方资产价值）；
- 手续费、网络费；
- 对手方/交易哈希（链上）。

## 三、最容易踩的坑

1. **把币币兑换当成“没卖”**：多数地区仍按处置计算。
2. **只导出交易所 CSV**：钱包、DeFi、NFT、空投没算进去。
3. **把转账当收入/亏损**：自己钱包间转账通常不是应税事件，但成本归属要记。
4. **忽略空投/质押/流动性收益**：可能按收入纳税，同时形成新的成本基础。
5. **用“税务优化”当逃税**：虚假成本、隐瞒收入的风险远高于省下的税。
6. **不区分长期/短期**：不同持有期的税率可能不同。

## 四、DeFi、NFT、空投怎么处理

- **DeFi 借贷**：利息/奖励通常要记录；抵押/清算可能触发处置；
- **流动性挖矿**：LP 代币、奖励、无常损失都要记录；
- **NFT**：铸造费、买入价、卖出价、版税、平台费都要保留；
- **空投**：确认取得时的价值、是否有锁仓/领取条件；部分地区的处理差异很大。

拿不准时，先记录“取得时间、数量、当时价值、来源”，再问当地税务顾问。

## 五、申报前的检查清单

- [ ] 所有交易所 CSV/API 记录已导出
- [ ] 钱包地址和链上交易已整理
- [ ] DeFi/质押/空投/NFT 已单独记录
- [ ] 每笔卖出都有成本基础
- [ ] 手续费、网络费已计入
- [ ] 区分收入与资本利得
- [ ] 保留原始文件至少当地要求年限
- [ ] 不确定的条目咨询专业人士

## 六、常见问题

**Q：只是买币并持有，要交税吗？**
A：通常买入/持有本身不产生应税事件，但卖出、兑换、消费或取得收益时可能要申报。

**Q：钱包之间转账要交税吗？**
A：通常不，但必须能证明地址归属和成本；频繁混用地址会增加核算难度。

**Q：交易所会帮我报税吗？**
A：多数不会替你完整申报；交易所报表只是其中一部分，尤其是链上/DeFi 数据。

**Q：亏损能抵税吗？**
A：部分地区允许资本损失抵扣/结转，规则不同；以当地税法为准。
