# VI 规范

## 品牌名称

- 中文：币圈指南研究社
- 英文：Crypto Guide Club
- 简写：CGC

## 品牌定位

面向中文加密用户的交易所与新手教育社群。核心价值是帮助用户看懂交易所、了解活动规则、降低操作风险。

## Logo 概念

Logo 由三部分构成：

- 金色圆章：可信、筛选、长期沉淀
- 指南针：方向、导航、避坑
- 字母 B：呼应“币圈指南”

## 主口号

看懂交易所，少走弯路。

## 辅助口号

- 不喊单，只做靠谱币圈导航
- 注册前先看指南，交易前先懂风险
- 新手少踩坑，老手提效率

## 字体

- 中文标题：Noto Sans SC / PingFang SC / Microsoft YaHei
- 英文数字：Inter / Arial
- 标题使用 700-850 字重
- 正文使用 400-500 字重

## 视觉风格

- 黑金为主，少量蓝/绿/橙用于功能状态
- 使用圆章、指南针、数据面板、风险提示块
- 避免“暴富”“喊单”“百倍币”视觉语言

## 使用禁区

- 不要把 Logo 拉伸变形
- 不要在复杂背景上直接放深色 Logo
- 不要将主色改成高饱和紫色、红色或荧光色
- 不要搭配“稳赚”“带单”“内幕”等营销词
