# 社群运营手册

## 社群目标

短期：

- 建立 1000 个高质量 Telegram 社群成员
- 每周稳定产出交易所活动汇总和新手教程
- 形成“网站教程 + X 分发 + Substack 沉淀 + Telegram 答疑”的闭环

中期：

- 成为中文用户查询交易所注册、费率、活动、风控的首选社区
- 建立交易所活动数据库和避坑案例库
- 培养高质量社群志愿答疑用户

长期：

- 做成“加密交易所选择与新手教育”的可信品牌

## 平台分工

### X

用途：流量入口、热点反应、短内容分发。

内容：

- 活动快讯
- 一图看懂注册流程
- 风险提醒
- 工具截图
- 交易所规则变化

频率：每天 2-4 条。

### Substack

用途：深度内容、邮件订阅、长期沉淀。

内容：

- 每周交易所活动周报
- 新手注册与安全专题
- 平台费率/活动对比
- 避坑案例复盘

频率：每周 1 篇。

### Telegram

用途：即时通知、社群答疑、活动反馈。

结构：

- 公告频道：只发正式内容
- 讨论群：提问、答疑、投票、反馈

频率：每天 1-2 条公告，每天 1 个讨论话题。

## 固定栏目

- 周一：本周交易所活动速览
- 周三：新手答疑夜
- 周五：避坑案例分享
- 周日：一周工具/交易所复盘

## 活动设计

- 新手安全自查挑战
- 交易所教程投票
- 交易所活动排行榜
- 避坑案例征集
- 社群贡献者徽章

## 核心指标

- X：曝光、互动率、网站点击率
- Substack：订阅数、打开率、点击率
- Telegram：入群人数、日活、有效提问数、垃圾消息比例
- 网站：社媒来源访问、文章停留、交易所注册链接点击
