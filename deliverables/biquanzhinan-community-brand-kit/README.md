# 币圈指南研究社 Brand Kit

社群品牌：币圈指南研究社  
英文名：Crypto Guide Club  
主口号：看懂交易所，少走弯路  
定位：不喊单的交易所与加密新手导航社群。

## 文件结构

- `logos/`：Logo SVG 源文件
- `social/`：X、Telegram、Substack 头图 SVG
- `png/`：由 SVG 导出的 PNG 文件
- `docs/`：VI 规范、社群规则、运营手册
- `templates/`：X、Substack、Telegram 发布模板
- `tokens/`：品牌颜色与 CSS 变量

## 推荐使用

- Telegram/X 头像：`png/logo-icon.png`
- 网站页脚或横幅：`png/logo-horizontal-dark.png`
- Substack 封面：`png/substack-cover.png`
- Substack 图标：`png/substack-logo.png`
- X 头图：`png/x-banner.png`
- Telegram 群封面：`png/telegram-banner.png`

## 品牌原则

不喊单、不代投、不承诺收益。内容以交易所教程、活动追踪、工具使用和安全提醒为主。
